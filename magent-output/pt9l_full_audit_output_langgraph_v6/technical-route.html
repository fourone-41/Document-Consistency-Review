LangGraph 节点架构

工程调度使用 LangGraph；专业判断由各 Agent 和工具完成。

基础节点

bootstrap

建立 Manifest、Readiness、PageIndex、SSOT、Relation Index 和机械候选。

scout_agent

确认产品类别、型号残留、法规基线和明显污染线索。

编排节点

orchestrator

按阶段轴与维度轴生成领域 Agent 任务包。

并行领域 Agent

regulatory_agent

法规、标签、说明书、标准、受控程序。

hardware_agent

硬件参数、BOM、PCB、电池、测量精度。

software_agent

软件需求、设计、测试、版本、追溯。

risk_agent

风险计划、风险评估、控制验证、剩余风险。

vv_agent

验证确认计划、报告、外部测试闭环。

dmr_agent

设计输出、图纸、BOM、工艺、包装与 SOP。

裁决节点

mechanical_review

机械候选聚类、多 Agent LLM 复审、补证据最终裁决。

evidence_gate

确认 finding 证据是否能回溯到 Markdown 原文。

challenge_agent

对语义 finding 做 keep/revise/drop/needs_more_context 裁决。

context_recovery

接收机械和语义待补证项，诊断缺口、补充上下文，并收敛为 confirm/dismiss/human_review。

输出节点

report

输出全量报告、错误汇总、机械裁决总表、驳回清单和人工任务。
