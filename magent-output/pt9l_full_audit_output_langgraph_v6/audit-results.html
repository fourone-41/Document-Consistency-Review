代表性确认问题

M001 / P1

正式外部测试报告引用 PT9C 风险管理报告

PT9L 的 ISO 14971 符合性验证表引用 `PT9C-FXGB01 V1.0`，导致 PT9L 风险管理合规证据链存在型号归属错误。

M002 / P1

硬件设计方案读图报告关键字段待填

Stage 06 正式文件标题栏中 Drawing NO.、Part name、Tolerance 等字段为“待填”，属于正式受控文件未完成。

M003 / P1

软件设计文件残留旧型号 BP3L

软件图样文件标题、文件名和图片资产路径使用旧型号 BP3L，文件主体身份标识未完成型号转换。

M007 / P1

PT9L 正式 BOM 引用 PT9C PCB 图号

EBOM 和 T1 样机 BOM 中 PCB 图号引用 `PT9C-CNTP01 V1.0`，构成异型号零件编号污染受控 BOM。

M012 / P2

客户需求书标题为血压计

文件标题和文件名使用“血压计”，内容实际为红外额温计 PT9L，存在产品品类标签与实际产品不符。

M017 / P1

设计输出清单接口板 PCB 引用 PT9C

正式设计输出清单一中接口板 PCB 图多个图层条目均引用 `PT9C-CNTP01 V1.0`，缺乏共用件声明或跨型号借用评审记录。
