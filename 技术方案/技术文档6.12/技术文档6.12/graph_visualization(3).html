可用查询语句 (点击填入)

MATCH (n:Requirement) RETURN n显示所有需求节点 MATCH (n:Risk) RETURN n显示所有风险节点 MATCH (n:Test) RETURN n显示所有测试节点 MATCH (n:Requirement)-[r]->(m) RETURN n,r,m需求及其关联 MATCH (n:Risk)-[r]->(m:RiskControl) RETURN n,r,m风险-控制措施 MATCH (n)-[r:TRACES_TO]->(m) RETURN n,r,m所有追溯关系 MATCH (n)-[r:VERIFIED_BY]->(m) RETURN n,r,m所有验证关系 MATCH (n)-[r]->(m) WHERE r.confidence='high' RETURN n,r,m高置信度关系 MATCH (n) WHERE n.label CONTAINS '温度' RETURN n搜索包含"温度"的节点 MATCH (n:Document)-[r]->(m) RETURN n,r,m文档及其关联 MATCH (n) RETURN n LIMIT 50显示前50个节点 MATCH (n)-[r]->(m) RETURN n,r,m显示全部有关系的节点
