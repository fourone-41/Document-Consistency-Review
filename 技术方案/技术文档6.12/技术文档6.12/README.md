# 医疗器械文档一致性审查系统展示包

打开方式：

1. 双击 `index.html` 查看主汇报页。
2. 页面中已嵌入小量文件知识图谱和多文件 Neo4j 风格图谱。
3. 两个图谱页使用 `vis-network` CDN；如果图谱区域空白，请确认电脑可以访问外网后刷新页面。

文件说明：

- `index.html`：主展示页面。
- `medical_device_doc_review_mindmap_presentation.svg`：汇报版流程图。
- `pilot_3files/kg_view.html`：3 份文件的小量知识图谱。
- `graph_visualization(3).html`：多文件 Neo4j 风格知识图谱。
