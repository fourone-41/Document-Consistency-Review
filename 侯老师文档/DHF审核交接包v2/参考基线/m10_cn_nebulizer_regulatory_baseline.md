# M10 雾化器 · 中国 NMPA 法规/标准基线（审核反向完备性子轴④ 的清单）

> **市场已核实：仅中国 CHN**（M10 客户需求书 2.0：■中国CHN/2025年，中国注册方■andon，环保■中国ROHS 2.0；美国□、欧盟□均未勾）。
> 监管 = **中国 NMPA**，不是 FDA。
> ⚠️ 两类"串错"都算真错：①体温计串品类残留（880.2910 / ISO 80601-2-56 / ASTM E1965 / 红外测温 / 温度量程）；②**反向拿 美国FDA/510k / 欧盟MDR/EN 当中国强制基准**（美/欧标准对仅中国项目是非强制，正确裁剪是对的；反向引用才是错）。
> 注：确切分类编码/管理类别(II/III类)与雾化器专用行标号以 PM/法规拍板和注册证为准，下表为审核对照基线，标"待确认"处需核。

## 1. 法规框架与上市路径（强制锚点）
| 项 | 基线 | 说明 |
|---|---|---|
| 上位法规 | 《医疗器械监督管理条例》(国务院令739号) | |
| 注册办法 | 《医疗器械注册与备案管理办法》(市监总局令47号) | |
| 分类 | 《医疗器械分类目录》—— 雾化器一般在 **08 呼吸、麻醉和急救器械** 项下；管理类别 **II 类**(待按目录与雾化方式确认具体编码) | 决定注册路径 |
| 上市路径 | **中国境内注册**：首次注册→注册检验→临床评价(雾化器多在《免于临床评价目录》,待确认)→技术审评→**发补**→取得**注册证**;配套**生产许可证** | **正好对应 M10 的"首次提交/发补提交/生产许可证扩证"** |
| **产品技术要求(PTR)** | 中国特有、注册核心文件:性能指标+检验方法 | 审核重点:PTR ↔ 设计输入/设计输出/注册检验报告 必须一致(下游≥上游) |
| 质量体系 | 《医疗器械生产质量管理规范》(GMP) + YY/T 0287(=ISO 13485) | 设计开发控制 |

## 2. 安全/性能标准（认可，强制对照；均用中国国标/行标，非 IEC/ISO 原版当强制基准）
| 标准 | 管什么 | 备注 |
|---|---|---|
| **GB 9706.1-2020** | 医用电气设备 通用安全(=IEC 60601-1 第3版国转;已并入EMC要求) | 强制 |
| 雾化器**并列/专用标准** | 视雾化方式(压缩/超声/振动筛网 mesh)对应的 YY 行标 | **待确认确切标准号**(如医用雾化器相关 YY 标准) |
| **YY/T 0316** | 风险管理对医疗器械的应用(=ISO 14971) | 03风险阶段依据;**不是** EN ISO 14971+A11(欧盟协调版) |
| **GB/T 16886 系列** | 生物相容性(=ISO 10993):口含嘴/面罩等患者接触件 | |
| 呼吸气体通路生物相容性 | 对应 ISO 18562(国内转化中,待确认 GB/T 号) | **雾化器特有**:气溶胶吸入通路浸出物/颗粒物,最易漏 |
| **YY/T 0664** | 医疗器械软件 软件生存周期过程(=IEC 62304) | M10 有软件方案/图样 → 适用;定软件安全等级 |
| **YY/T 1474** | 可用性工程(=IEC 62366) | 家用/患者操作 |

## 3. 标签与 UDI（强制）
- 《医疗器械说明书和标签管理规定》
- **医疗器械唯一标识(UDI)系统规则**(NMPA;M10 文件里已有"M10彩盒UDI标签/外箱UDI标签") → 审核 UDI 标签要素、DI/PI、与注册证/技术要求一致
- 说明书要素:预期用途、适用药液/人群、禁忌、警告、清洗消毒、生产/注册信息

## 4. 雾化器关键性能参数（横向参数槽位 应抽取并全链比对——物理量与市场无关）
- **气溶胶输出率 / 雾化率**(mL/min 或 mg/min)、**总输出量**
- **MMAD 质量中值空气动力学直径**(µm)、**可吸入比例/<5µm 占比**、GSD
- **储药杯容量**(mL)、**残留药量**(mL)
- **噪音**(dB(A))、**工作电压/电流/功率**(电池型加容量/续航)
- **雾化方式**(压缩/超声/振动筛网 mesh)、适用药液、适用人群、家用/医用
- 工作/储存环境、清洗消毒、寿命/循环次数

## 5. 审核要点（反向查"该有却没有" + 串错）
1. 立项/设计输入是否锚定 **分类目录编码 + II类 + 中国注册路径 + PTR**？
2. **产品技术要求(PTR)** 的性能指标(雾化率/MMAD/残留量…)是否与设计输入、注册检验报告、说明书全链一致？(这是中国注册的核心对账)
3. 性能是否覆盖雾化器专标 + GB 9706.1-2020？生物相容性是否含呼吸气路(ISO 18562 对应)？
4. 软件(07/10)是否按 **YY/T 0664** 定安全等级？
5. 风险(03)是否用 **YY/T 0316 / ISO 14971:2019**，而非欧盟协调版 EN ISO 14971+A11 反向引用？
6. UDI 标签要素是否齐、与注册证/PTR 一致？
7. 全链是否出现 **体温计串品类残留**(880.2910/红外测温/温度量程/ASTM E1965) = 真错。
8. 是否误把 **FDA/510k/UDI(美版)/EU MDR/EN/CE** 当中国强制基准(仅中国应裁剪;反向引用=真错)。
9. **三版 DMR(V1/V2/V3)** 与 **两个设计变更(17/18)** 是否随注册发补同步更新了 PTR/设计输出/检验？(发补改了什么、回溯到位没)
