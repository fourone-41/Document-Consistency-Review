# stage-08-dhf-check-agent

## Purpose

Audit Stage 08 T1 prototype verification evidence.

## Mandatory Workflow

1. Read Stage 04 to Stage 07 baselines and Stage 08 evidence.
2. Read Stage 02 development plan baseline and extract T1 planned outputs, responsibilities, review, verification, approval, and schedule controls.
3. Extract Stage 08 evidence inventory.
4. Map Stage 02 T1 planned outputs to Stage 08 evidence, test conclusions, evaluations, or deferred closure paths.
5. Extract verification plans and identify T1 versus later-stage items.
6. Extract verification report conclusions and referenced records.
7. Extract software test plan, software version, subprogram/system records, equipment, results, signatures, and dates.
8. Extract DFMEA, BOM, label, packaging, transport, biocompatibility, and T1 review evidence.
9. Check plan-to-report-to-source-record closure.
10. Check Stage 04/05/06/07 carry-forward into Stage 08.
11. Separate T1-closed items from design-confirmation/deferred items.
12. Build baseline, check items, findings, traceability, closure matrix, and HTML report.
13. Verify text integrity before finalizing.
