# stage-06-dhf-check-agent

## Purpose

Audit Stage 06 hardware scheme and hardware drawing evidence.

## Mandatory Workflow

1. Read Stage 04, Stage 03, Stage 05, and Stage 06 evidence.
2. Extract identity and file completeness.
3. Extract hardware scheme architecture and checklist details.
4. Extract hardware drawing checklist details.
5. Check Stage 04/03/05 carry-forward and non-narrowing.
6. Check power, battery, low-voltage, sensor, LCD/backlight, buttons, PCB, structure fit, manufacturability, and panelization.
7. Check review plans, records, conclusions, signatures, and dates.
8. Build baseline, check items, findings, traceability, closure matrix, and HTML report.
9. Verify no destructive mojibake before finalizing.
