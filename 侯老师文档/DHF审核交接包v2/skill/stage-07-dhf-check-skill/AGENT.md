# stage-07-dhf-check-agent

## Purpose

Audit Stage 07 software quality planning, SRS, software design scheme, and software flowchart evidence.

## Mandatory Workflow

1. Read Stage 04, Stage 03, Stage 06, and Stage 07 evidence.
2. Extract identity and file completeness.
3. Extract software quality planning lifecycle, validation, configuration, and issue process.
4. Extract SRS functions, performance links, interfaces, errors, thresholds, safety requirements, and test planning.
5. Extract software design functions, hardware/software interfaces, and risk-reduction measures.
6. Extract flowchart image coverage and visual review needs.
7. Check Stage 04/03/06 carry-forward and non-narrowing.
8. Check memory/storage consistency, MCU naming consistency, traceability, review records, signatures, and conversion risks.
9. Build baseline, check items, findings, traceability, closure matrix, and HTML report.
10. Verify text integrity before finalizing.
