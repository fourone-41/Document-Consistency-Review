# Skill: 3D模型基础分析

## 目的

从3D模型（STP/STEP文件）提取**外部可见的几何信息**，建立零件和装配体的基础认知，为后续剖面分析和2D图纸对照提供参照。

## 核心原则

### 信息边界

**可以直接获取（事实）：**


| 信息类型              | 获取方法                     | 精度      | 用途                 |
| ----------------- | ------------------------ | ------- | ------------------ |
| 包围盒(Bounding Box) | `shape.BoundingBox()`    | ±0.01mm | 确定空间占位、主轴方向、嵌套可能性  |
| 零件数量（装配体）         | `TopExp_Explorer(SOLID)` | 精确      | 确认装配体规模            |
| 体积                | `BRepGProp`              | ±0.1mm³ | 与 bbox 体积对比，估算空心比例 |


**可以通过计算获取：**


| 信息类型    | 方法       | 局限   |
| ------- | -------- | ---- |
| 外轮廓（投影） | 三视图投影    | 遮挡问题 |
| 对称性     | 几何比较     | 计算复杂 |
| 空间位置关系  | bbox重叠计算 | 仅粗略  |


**不可获取（需要其他方法）：**


| 信息类型 | 所需方法     |
| ---- | -------- |
| 内部结构 | 剖面分析     |
| 壁厚   | 剖面分析     |
| 配合间隙 | 剖面+测量    |
| 功能用途 | 技术文档     |
| 材料   | BOM/技术文档 |

## 分析流程

### 第一步：文件识别与加载

```python
# 单个零件
part = cq.importers.importStep("part.stp")
shape = part.val()

# 装配体
assembly = cq.importers.importStep("assembly.stp")
shape = assembly.val()

# 判断类型
if shape.ShapeType() == TopAbs_COMPOUND:
    print("这是装配体")
else:
    print("这是单个零件")
```

### 第二步：基础几何量提取

#### 2.1 Bounding Box 分析

```python
bb = shape.BoundingBox()

report = {
    "X范围": (bb.xmin, bb.xmax),
    "Y范围": (bb.ymin, bb.ymax),
    "Z范围": (bb.zmin, bb.zmax),
    "长度_X": bb.xmax - bb.xmin,
    "宽度_Y": bb.ymax - bb.ymin,  # 或高度，取决于坐标系
    "高度_Z": bb.zmax - bb.zmin,
    "几何中心": ((bb.xmin+bb.xmax)/2, (bb.ymin+bb.ymax)/2, (bb.zmin+bb.zmax)/2),
}
```

**从bbox可以推断：**

- 主轴方向：最长的轴
- 大致形态：长条形(圆柱)、扁平形(盘)、立方形
- 对称性暗示：如果X和Z范围对称于0，可能是轴对称

**不能推断：**

- 实际形状（球和立方体可能有相同bbox）
- 内部是实心还是空心

#### 2.2 装配体零件分解

```python
from OCP.TopExp import TopExp_Explorer
from OCP.TopAbs import TopAbs_SOLID
from OCP.TopoDS import TopoDS

solids = []
explorer = TopExp_Explorer(shape.wrapped, TopAbs_SOLID)
while explorer.More():
    solid = TopoDS.Solid_s(explorer.Current())
    solids.append(solid)
    explorer.Next()

print(f"装配体包含 {len(solids)} 个独立实体")
```

#### 2.3 各零件bbox对比

```python
for i, solid in enumerate(solids):
    bb = get_solid_bbox(solid)  # 自定义函数
    print(f"Solid {i}: X({bb.xmin:.1f}~{bb.xmax:.1f}) "
          f"Y({bb.ymin:.1f}~{bb.ymax:.1f}) "
          f"Z({bb.zmin:.1f}~{bb.zmax:.1f})")
```

**从对比可以推断：**

- 哪些零件在轴向上重叠（可能嵌套或并列）
- 哪些零件径向范围最大（可能是外壳）
- 哪些零件径向范围最小（可能是内芯/针/轴）

### 第四步：实/空比例估算（可选）

```python
from OCP.GProp import GProp_GProps
from OCP.BRepGProp import BRepGProp

props = GProp_GProps()
BRepGProp.VolumeProperties_s(shape.wrapped, props)
volume = props.Mass()  # 实际体积

bb = shape.BoundingBox()
bbox_volume = (bb.xmax - bb.xmin) * (bb.ymax - bb.ymin) * (bb.zmax - bb.zmin)

fill_ratio = volume / bbox_volume
print(f"实体体积: {volume:.1f} mm³")
print(f"包围盒体积: {bbox_volume:.1f} mm³")
print(f"填充率: {fill_ratio*100:.1f}%")
# 填充率 < 30% → 多半是壳体/筒形/带大空腔
# 填充率 > 70% → 多半是实心或仅小孔
# 30%~70% → 中等复杂度
```

**用途**：仅用于判断"是否值得做剖面分析"。

- 高填充率 + 简单bbox → 可能是实心零件，剖面价值低
- 低填充率 + 大bbox → 必有内部腔体，剖面优先级高

## 常见陷阱与应对

### 陷阱1：把bbox当作实际形状

**错误示例**：

> P04 外径约 36mm（基于bbox X范围 ±18）

**问题**：bbox是包围盒，不是实际轮廓。零件可能有凸起使bbox变大。

**正确做法**：

> P04 bbox X范围 ±18.2mm，实际外径需要通过横截面测量验证

### 陷阱2：忽略坐标系方向

**错误示例**：

> 零件高度52mm（Y范围1~52.6）

**问题**：不同STP文件可能使用不同坐标系，Y可能不是"高度"方向。

**正确做法**：

1. 先观察装配体整体形态
2. 确定哪个轴是"轴向"（通常是最长轴或对称轴）
3. 明确标注"Y轴方向定义为xxx"

### 陷阱3：单独零件vs装配体位置

**错误示例**：

> P04 Y范围是 -0.3~~24，P02 Y范围是 1~~52.6，所以P04在P02内部

**问题**：单独零件STP的坐标系可能与装配体不同。

**正确做法**：

1. 如果有装配体STP，从装配体中读取位置
2. 如果只有单独零件，只能报告相对尺寸，不能断言装配位置
3. 明确标注"以下位置来自装配体"或"以下为独立零件坐标"

### 陷阱4：功能推测

**错误示例**：

> 该零件是一个弹簧，用于提供复位力

**问题**：3D模型只能显示形状，不能确定功能。螺旋形可能是弹簧，也可能是螺纹或装饰。

**正确做法**：

> 该零件呈螺旋形，外径30mm，螺距2mm，圈数12圈
> （如需确认是否为弹簧及其功能，需参考技术文档）
