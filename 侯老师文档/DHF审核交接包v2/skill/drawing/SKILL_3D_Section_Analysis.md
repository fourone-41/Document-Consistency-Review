# Skill: 3D模型剖面分析

## 目的

从3D模型（STP/STEP文件）生成系统化的剖面图，提取零件内部结构和配合关系的**可测量几何信息**。

## 核心原则

### 信息边界

**可以获取的信息（事实）：**

- 几何尺寸：直径、半径、壁厚、高度、深度（精度±0.1mm）
- 空间位置：零件在装配体中的坐标范围（Bounding Box）
- 拓扑关系：包围、嵌套、并列、接触、间隙
- 截面轮廓：闭合/开放、对称性、特征数量

**不可获取的信息（需要其他来源）：**

- 功能用途（需要技术要求文档）
- 运动方式（需要运动学分析或说明书）
- 材料属性（需要材料清单）
- 装配顺序（需要工艺文档）
- 公差配合（需要2D图纸标注）

### 避免假设

- ❌ 不要说"这是一个锁定机构"（功能推测）
- ✅ 应该说"该位置有3个径向凸起，高度2mm，间距120°"（几何事实）
- ❌ 不要说"弹簧套在支架外面"（位置关系模糊）
- ✅ 应该说"弹簧外径30mm，位于支架外圈(R=18.6mm)与内腔(R=7.5mm)之间的环形空间"（精确位置）

## 剖面选取策略

### 总原则

1. **每一刀都要有理由**：剖面位置必须对应一个具体的几何特征或一个待回答的问题，禁止"凑均匀"。
2. **间距由局部决定**：横截面密度由"局部特征关键尺寸"（凸起高度、槽宽、卡爪厚度等）决定，与装配体整体尺寸无关。
3. **功能轴对齐优先**：对于有明显功能轴的特征（轴/孔的轴线、卡爪悬臂方向、滑动副的运动方向、旋转副的旋转轴），必须有一张剖面与该轴对齐。
4. **分轮迭代**：粗看 → 列特征 → 针对性细看 → 配合分析 → 必要时回头补剖面。
5. **可逆性**：允许在后续轮次发现"前一轮剖面选错了"，标注废弃后重做，不要将就用。

### 功能轴对齐规则

对以下结构，必须各做至少 1 张沿"可能的功能轴"的剖面：

| 结构类型 | 功能轴 | 必做剖面 |
|---------|-------|---------|
| 轴/孔配合 | 轴线 | 沿轴线的纵剖面 |
| 台阶/凸缘 | 轴线 | 沿轴线的纵剖面 |
| 槽（环槽、键槽、滑槽） | 槽底走向 | 沿槽长度方向的纵剖面 |
| 局部凸台/凸起 | 凸起方向 | 沿凸起对称面的纵剖面 |
| 不对称凸出/卡爪 | 悬臂方向 | 沿悬臂中线的纵剖面 |
| 旋转副 | 旋转轴 | 垂直于旋转轴的横截面 |
| 滑动副 | 运动方向 | 沿运动方向的纵剖面 |

**关键**：如果剖面不与功能轴对齐，即使切了再多也无法看清该特征。

### 第一步：获取装配体整体信息

```
1. 加载装配体STP
2. 计算整体Bounding Box，确定主轴方向（通常是最长轴）
3. 识别所有独立Solid数量
4. 对每个Solid计算独立bbox，初步判断空间分布
```

注意：bbox 的"最长轴"只是**几何主轴**，不一定等于零件的**功能轴**。
功能轴需要从特征观察（例如螺纹方向、卡扣朝向）中识别。

### 第二步：选择剖面类型

剖面选取是迭代过程，分三轮，每一轮的发现决定下一轮的选点。
**禁止用整体尺寸做等距采样**，必须每一刀都对应一个具体的几何理由。

#### 第 0 轮：定向剖面（必选，仅用于建立坐标感）

**目的**：仅仅是为了知道"主轴在哪、零件大致怎么排布"，不试图回答任何配合问题。

**剖面集**（共 3~4 张）：
- 主轴纵剖面：X=0、Z=0 各一刀（沿主轴的两个正交纵剖面）
- 横截面：在主轴上 1~2 个明显位置（如装配体几何中心、明显的台阶过渡处）

**禁止做的事**：
- 不要在这一轮就密集采样
- 不要试图测配合间隙
- 不要给出"M01在P04内部"这类配合判断

**应当输出**：
- 哪些零件出现在主轴剖面上、各自的轴向区段
- 主轴剖面上看到的明显几何特征列表（"Y=10附近P07外圈有一处径向凸起"、"P04下半部有内外两层壁"等）
- **特征清单（feature inventory）**——用于驱动第 1 轮

#### 第 1 轮：特征驱动剖面（核心）

**核心原则**：每一刀都必须能用一句话回答"我在看什么几何特征"。

**驱动来源**：第 0 轮特征清单 + 已知零件功能轴（如旋转副的旋转轴、卡扣的弹性悬臂方向）。

**针对不同特征类型的剖面策略**：

| 特征类型 | 必加剖面 | 间距决定 |
|---------|---------|---------|
| 轴/孔配合 | 沿轴向 1 张纵剖面 + 配合段两端各 1 张横截面 | 端点定位即可，不需序列 |
| 台阶/凸缘 | 跨过台阶的纵剖面 + 台阶两侧各 1 张横截面 | 横截面距台阶面 0.5~1mm |
| 槽/凹陷 | 沿槽长度方向纵剖面 + 槽中点 + 槽两端 各 1 张横截面 | 横截面间距 = min(槽宽/3, 1mm) |
| 局部凸起/凸台 | 凸起中心 + 凸起根部 + 凸起末端 各 1 张横截面；凸起对称面纵剖面 | 间距 = min(凸起高度/2, 1mm) |
| 不对称凸出/卡爪 | 沿凸出对称面 1 张纵剖面 + 凸出根部、中部、末端 3 张横截面 | 视卡爪长度决定 |
| 开窗/穿孔 | 穿过窗中心的两个正交纵剖面 + 窗上下边缘各 1 张横截面 | 横截面距窗边 0.5mm |
| 螺纹/螺旋 | 沿螺旋轴 1 张纵剖面（不要靠横截面理解螺纹） | — |

**横截面间距规则**（关键，与整体尺寸无关）：
```
间距 = min(局部特征关键尺寸 / 3, 1mm)

其中"局部特征关键尺寸"取以下最小值：
- 该特征的最小厚度（如卡扣悬臂厚度）
- 该特征的最小高度（如凸起轴向高度）
- 该特征的最小开口（如槽宽、窗高）
```

**示例**：P07 卡扣区域分析
```
第 0 轮观察到：P07 外圈在 Y≈10~12mm 区段有 R 值跳变（从 21.0 到 22.5）
特征类型：局部凸起（凸起高度≈1.5mm）
特征驱动剖面：
- 横截面：Y = 9.5, 10, 10.5, 11, 11.5, 12, 12.5（间距 0.5mm，覆盖凸起轴向区段）
- 纵剖面：X=0、X=22（穿过凸起对称面，需要先确定凸起的角度位置）

注意：纵剖面的 X 值取决于"凸起在哪个角度"——这必须在第 0 轮的横截面已经看出来，
否则无法选择。如果第 0 轮看不出凸起角度位置，需要先做一张包含凸起高度的横截面
（比如 Y=11mm），从横截面上读出凸起角度，再补做纵剖面。
```

#### 第 2 轮：配合驱动补充剖面

**触发条件**：第 1 轮发现两零件在某区域有复杂接触，单一剖面不足以说清。

**补充策略**：见下方"配合关系分析方法"。

#### 关于"信息发现的可逆性"

剖面选取是迭代的，**完全允许"在配合分析中发现新特征 → 回头补做剖面"**。
具体迭代流程：

```
第 0 轮 → 特征清单 → 第 1 轮特征剖面 → 配合分析
                                          │
                                          ↓
                              发现新疑问？
                                  │      │
                                  否     是
                                  ↓      ↓
                                结束   补做第 2 轮剖面 → 重新分析
```

**记录原则**：
- 每张剖面图命名要包含"为何而切"，例如 `A3E_P07hook_Y10.5.png` 而不是 `A3E_cross_5.png`
- 在分析报告中明确每张图回答了哪个问题
- 如果某轮新发现否定了之前的剖面选择，**保留旧剖面但标注"已被 XXX 替代"**，避免后续误用

## 配合关系分析方法

### 场景1：同轴嵌套（如M01在P04内部）

**问题**：单看外径无法理解实际空间关系

**方法**：

```
1. 对两个零件分别做轴向剖面
2. 叠加到同一坐标系
3. 识别以下几何量：
   - 外零件的内腔边界（多个同轴圆/环）
   - 内零件的外边界
   - 两者之间的空隙分布
```

**输出模板**：

```
P04 支架1 同轴结构（Y=10mm 截面）：
├─ 外圈：R = 18.6mm（外壁）
├─ 中圈：R = 15.0mm（内腔外壁）
├─ 内腔：R = 7.5mm（中心孔）
└─ 环形空间：R = 7.5~15.0mm（可容纳零件）

M01 弹簧：
├─ 外径：R = 15.0mm
└─ 内径：R = 12.5mm

配合关系：
M01 位于 P04 的中圈空间（R=7.5~15.0mm）内，
外表面与P04中圈内壁(R=15.0mm)贴合或有微小间隙
```

### 场景2：局部开孔穿透（如P02穿过P07开孔）

**问题**：单一剖面可能错过开孔或穿透结构

**方法**：

```
1. 先在接触区域做 1~2 张横截面（如配合段中点），从横截面读出：
   - 开孔的轴向高度范围（窗的上下边缘 Y_top, Y_bot）
   - 开孔的角度位置（θ1, θ2, ...）
   
2. 基于第 1 步读到的开孔尺寸决定密集序列间距：
   间距 = min(开孔轴向高度 / 4, 1mm)
   位置 = Y_bot - 1mm 到 Y_top + 1mm
   （注意：是开孔尺寸，不是装配体尺寸，也不是配合段尺寸）

3. 在开孔角度位置做纵剖面（X 或 Z 取经过开孔中心的值）
   - 如果开孔在 θ=0°/120°/240°，则做 X=0、X=cos(120°)*R、X=cos(240°)*R 三张
   - 用纵剖面看开孔的轴向形状

4. 识别以下模式：
   - "仅A存在" → A独立区
   - "仅B存在" → B独立区  
   - "A包围B" → A外B内
   - "A和B分离但并列" → 并列区
   - "A穿过B的空腔" → 穿透区
```

**输出模板**：

```
P02-P07 轴向配合分析：

Y=0mm：仅P07（高度起点）
Y=3mm：P07外圈 + P02在P07开孔内穿过
Y=5mm：P07外圈 + P02并列（P02在内侧）
Y=10mm：P07外圈（含卡钩凸起H=2mm）+ P02内壁
Y=13.5mm：仅P02（P07顶端）

开孔特征：
- 位置：P07在θ=0°, 120°, 240°处有3个径向开孔
- 开孔尺寸：宽度5mm，高度8mm（从Y=2mm到Y=10mm）
- P02的凸耳穿过这些开孔
```

### 场景3：卡钩/弹性结构

**问题**：需要判断形变空间和脱开条件

**可以从剖面获取的信息**：

```
1. 几何测量：
   - 卡钩根部位置（R值）
   - 卡钩根部截面厚度
   - 卡钩悬臂长度（径向延伸）
   - 卡钩末端凸起尺寸
   - 卡钩与配合零件的名义间隙

2. 通过序列剖面追踪：
   - 卡钩的轴向范围（从哪个Y到哪个Y）
   - 卡钩数量和分布角度
   - 卡钩形状随高度的变化

3. 通过多角度剖面：
   - 卡钩的三维形态
   - 是否有减弱槽/应力集中点
```

**不能从剖面获取的信息（需要其他分析）**：

```
1. 需要材料力学分析：
   - 卡钩的弯曲刚度
   - 产生特定形变所需的力
   - 疲劳寿命

2. 需要接触分析/实测：
   - 卡钩与配合面的实际接触状态
   - 脱开所需的轴向/径向力
   - 组装/拆卸是否可逆

3. 需要公差分析：
   - 考虑公差后的极限间隙
   - 是否存在干涉风险
```

**方法（以P07卡钩为例，演示迭代过程）**：

```
[轮 0 — 定向剖面]
- 主轴纵剖面 X=0：观察到 P07 的轴向位置 Y=0~13.5mm
- 横截面 Y=7（P07 轴向中点）：观察到 P07 是一个有局部凸起的圆环

第 0 轮特征清单：
- F1: P07 轴向 0~13.5mm 是圆环主体
- F2: P07 在某处有径向凸起（位置和高度未知）

[轮 1 — 特征剖面]
基于 F2，先用横截面定位凸起的轴向位置：
- 试探横截面 Y=4, 7, 10, 13（覆盖 P07 全长，间距由 P07 高度 13.5/4 决定）
- 发现：Y=10、Y=12、Y=13 横截面上的 R_max 不同 → 凸起在 Y≈10~13 之间

确定凸起位置后，按"凸起高度/2"加密：
- 加密横截面 Y=10, 10.5, 11, 11.5, 12, 12.5（间距 0.5mm）
- 测量每张图的 R_min、R_max → 数据如下表

确定凸起角度后，做对称面纵剖面：
- 纵剖面经过凸起角度（从横截面读出，如 X=22cosθ）
- 用纵剖面看凸起的轴向形状、根部厚度、悬臂长度

[轮 2 — 配合剖面]
将 P07 凸起所在区段的横截面与 P02 内壁叠加：
- 测量名义间隙
- 决定是否再加密（如发现凸起与 P02 是干涉量很小的卡合，需要 0.2mm 间距精测）
```

**输出模板**：

```
P07 卡钩结构分析（基于序列剖面）：

测量数据：
| Y (mm) | R_min (mm) | R_max (mm) | 观察 |
|--------|------------|------------|------|
| 8      | 20.10      | 21.04      | 外圈主体 |
| 9      | 20.10      | 21.05      | 外圈主体 |
| 10     | 20.60      | 21.05      | R_min上升，内腔收窄 |
| 11     | 20.10      | 21.06      | 恢复 |
| 12     | 20.10      | 22.50      | R_max突增1.44mm→卡钩凸起 |

几何推断：
- 卡钩凸起位于Y≈12mm
- 凸起高度≈22.50-21.06=1.44mm
- 与P02内壁(R≈20.2)的名义间隙≈22.50-20.2=2.3mm（凸起超出P02）
- 卡钩轴向范围：Y=10~13.5mm

待确认（超出几何分析范围）：
- 卡钩是否需要弹性变形才能越过P02？
- 如需变形，所需力是多少？
- 这是装配后永久卡合还是可拆卸？
```

### 场景3B：复杂同轴结构（如M01在P04内部）

**问题**：简单说"A套在B里面"不足以描述实际空间关系

**方法（迭代）**：

```
[轮 0]
- 单零件横截面 1 张（P04 中点 Y=12）：观察是否单层圆环、双层圆环、多层圆环
  → 假设观察到 P04 是双层结构（外壁 R≈18.9 + 内腔 R≈7.3）
- 单零件主轴纵剖面 1 张：观察内外两层壁的轴向连续性

第 0 轮特征清单：
- F1: P04 是同轴双层壳体
- F2: P04 内外壁之间有环形空间（具体宽度需测）

[轮 1]
针对环形空间，做以下剖面：
- 横截面：在轴向几个特征位置（不是等距，而是看主轴纵剖面上的台阶/过渡处）
  例如 P04 主轴纵剖面显示 Y=15 处内壁有收窄 → 在 Y=14、15、16 各加 1 张
- 测量每张横截面的 R_外、R_内 → 得到环形空间的轴向变化

[轮 2]
将 M01 与 P04 的横截面叠加：
- 在 M01 出现的轴向区段（Y=0~24）取相同 Y 的截面
- 比较 M01 弧线位置 vs P04 环形空间边界
- 形成"半包围"等准确描述
```

**输出模板**：

```
P04 支架1 同轴结构（基于Y=2~20mm序列剖面）：

各高度截面测量：
| Y (mm) | R_外 (mm) | R_内 (mm) | 环形空间 |
|--------|-----------|-----------|----------|
| 2      | 18.8      | 7.4       | 7.4~18.8 |
| 5      | 18.8      | 7.4       | 7.4~18.8 |
| 10     | 18.9      | 7.3       | 7.3~18.9 |
| 15     | 18.9      | 5.7       | 5.7~18.9（内腔收窄）|
| 20     | 18.9      | 7.2       | 7.2~18.9 |

P04 结构描述：
├─ 外壁：R≈18.8~18.9mm（锥形，下小上大）
├─ 内腔：R≈5.7~7.4mm（有变化）
└─ 环形空间：R=5.7~7.4mm 到 R=18.8~18.9mm

M01 弹簧：
├─ 截面形态：弧形（螺旋弹簧的一圈）
├─ 弧线位置：R≈12~15mm
└─ 轴向范围：Y=0~24mm

配合关系：
M01 弹簧位于 P04 的环形空间（R=7~19mm）内部，
弹簧外径(R≈15mm)小于P04外壁(R≈18.9mm)，
弹簧内径(R≈12mm)大于P04内腔(R≈7mm)，
形成"M01包围P04内腔，但被P04外壁包围"的半包围结构。
```

## 注意事项

1. **BRepAlgoAPI_Section 的局限**：
  - 对于纯圆柱面切圆柱轴线，可能不产生边（数学退化）
  - 解决方案：用序列横截面+径向测量代替
2. **TopoDS_Shape 类型转换**：
  - `TopExp_Explorer` 返回的是 `TopoDS_Shape`
  - 需要用 `TopoDS.Edge_s()` 转换后才能用于 `BRepAdaptor_Curve`
3. **单位一致性**：
  - STP文件通常使用mm
  - matplotlib默认无单位，需要在图表中标注
4. **中文字体**：
  - 设置 `matplotlib.rcParams['font.sans-serif'] = ['Microsoft YaHei']`
